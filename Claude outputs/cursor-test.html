Troubleshooting

If you don't see a custom cursor:

  • Check your browser console for any errors (F12 → Console)
  • Some browsers may not support data URI cursors
  • Try refreshing the page (Ctrl+Shift+R or Cmd+Shift+R)
  • Try a different browser (Chrome, Firefox, Safari, Edge all support this)

Expected Behavior:

When you move your cursor over the purple-tinted sections, you should see a stylized "C" logo cursor (purple color) instead of the normal arrow.

SVG Cursor Code:

cursor: url('data:image/svg+xml;charset=utf-8,...') 16 16, auto;
